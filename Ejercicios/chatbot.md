## Características del ChatBot:

### 🎯 Temas cubiertos:

- Python: Variables, listas, diccionarios, funciones, clases, módulos, errores, comprehensions, decoradores

- Machine Learning: Algoritmos (regresión, árboles, KNN, SVM, Random Forest), evaluación (overfitting, accuracy, precision), librerías (scikit-learn, TensorFlow, PyTorch)

### 🔧 Funcionalidades:

- Base de datos SQLite para persistencia
- Umbral de similitud del 70% para respuestas
- Respuesta por defecto cuando no encuentra información
- Entrenamiento con más de 50 conversaciones predefinidas

### 📦 Para usar el código:

1. Instalar dependencias:

   _pip install chatterbot chatterbot-corpus_

2. Ejecutar el script:

   _python chatbot\*ml.py_

3. Probar preguntas como:

- "¿Qué es una lista en Python?"
- "¿Qué es Machine Learning?"
- "¿Cómo funciona Random Forest?"
- "¿Qué es overfitting?"

### 💡 Ventajas:

- Aprende de cada conversación
- Persistencia en base de datos
- Fácil de extender con más conocimiento
- Manejo de errores robusto
